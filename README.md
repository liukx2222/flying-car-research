# 小鹏汇天「陆地航母」飞行汽车调研网页

## 文件
- `index.html`：网站入口文件，包含完整调研报告。可直接用浏览器打开。
- `README.md`：部署说明。

## 发布到 GitHub Pages
1. 注册/登录 GitHub，创建一个新的 Public 仓库。
2. 将 `index.html` 上传到仓库根目录（确保文件名就是 `index.html`）。
3. 进入仓库 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/(root)`，点击 Save。
6. 等待部署完成，GitHub 会生成形如 `https://用户名.github.io/仓库名/` 的网页链接。
7. 将该网页链接提交到课程作业收集入口。

## 提交前建议
- 用浏览器检查页面和链接。
- 将封面处的课程信息按老师要求补充姓名、学号、班级。
- 本网页的技术评价为课程调研分析；涉及量产配置、适航证件状态等信息，请以最新官方公告为准。
